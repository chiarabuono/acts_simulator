# Overview

This repository is the software implementation of the Master's thesis *"Modeling and Control of Cable-Driven UAV Systems for Collaborative Load Manipulation"* (Chiara Buono, École Centrale de Nantes / Università di Genova, 2026), carried out in the context of the ShieldBot project's FaçadeShieldBot application.

The thesis studies an **Aerial Cable-Towed System (ACTS)**: a payload suspended and actuated by a combination of aerial vehicles (UAVs) and ground-based winches, connected via cables. This thesis address the design problem of the ACTS itself: systematically choosing how many cables to use, where to attach them on the payload, and how to route them to the ground anchors. These are design decisions made once, before deployment, and then fixed — yet they directly determine the achievable workspace, wrench-generation capability, controllability, and robustness of everything built on top of them.
